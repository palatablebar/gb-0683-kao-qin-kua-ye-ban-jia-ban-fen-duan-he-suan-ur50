# 夜班反例

18位员工各有10月1日22点进、10月2日06点出。02点至03点休息，实际7小时，前两小时是假日3倍，次日5小时正常1倍，20元时薪合计220元。直接把整个夜班按归属日计假日会错算420元。脏批额外含缺时薪、冲突打卡、BOM、短行、空行与重复表头。

# 早到与延时裁决

员工2026-10-05(周一)班22:00–06:00、02:00–03:00休息、时薪20。20:00提前进场、07:00延时离场：提前段20:00–22:00计120分钟1倍40元，不占正常额度；计划段420分钟1倍140元；延时段06:00–07:00计60分钟1.5倍30元；合计600分钟210元。若从实际进场累计额度，跨日额度重置使延时60分钟只按1倍计，合计200元，延误加班被少付；若计划外一律按加班，早到120分钟按1.5倍计，合计230元，普通早到被多付。再例：班18:00–02:00、22:00–23:00休息，13:00提前5小时进场、02:00准时离场。裁决后提前段300分钟1倍100元、计划段420分钟1倍140元，合计240元；若从实际进场累计额度，当日480分钟额度被提前段占去300分钟，计划内120分钟被误推入1.5倍，合计260元。
